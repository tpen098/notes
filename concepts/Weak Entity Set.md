# Weak Entity Set

## Definition

A [[Weak Entity Set]] is an [[Entity Set]] whose existence is dependent on another [[Entity Set]] called [[Identifying Entity Set]] [^1]

> [!EXAMPLE] Example
> A section [[Entity Set]] is a [[Weak Entity Set]] because there cannot be a section without the course [[Entity Set]]
