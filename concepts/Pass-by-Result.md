# Pass-by-Result

## Definition

[[Pass-by-Result]] is an implementation model for parameter passing in [[Subprogram Parameter|Subprogram Parameters]] where no value is transmitted to the [[Subprogram]]. The corresponding [[Subprogram Parameter|Formal Parameter]] acts as a [[Local]] [[Variable]] to the [[Subprogram]]. Just before the [[Subprogram]] returns the control to the caller, the final value of the [[Subprogram Parameter|Formal Parameter]] is transmitted to the caller's [[Subprogram Parameter|Actual Parameter]].
