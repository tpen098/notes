# Subprogram Parameter

## Definition

[[Subprogram Parameter|Subprogram Parameters]] are [[Variable|Variables]] provided to a [[Subprogram]] in the [[Subprogram Definition]]. The placeholder variables are called [[Subprogram Parameter|Formal Parameters]] while the actual values and [[Programming Expression|Programming Expressions]] provided are the [[Subprogram Parameter|Actual Parameters]].
