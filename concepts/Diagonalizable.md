# Diagonalizable

## Definition

A [[Square Matrix]] $A$ is [[Diagonalizable]] if it is [[Similar]] to a [[Diagonal Matrix]]. In other words, if there exists an invertible [[Square Matrix]] $P$ such that the following holds then [[Matrix]] $A$ is [[Diagonalizable]].

$$
D = P^{-1}AP
$$

## Diagonalizability of Similar Matrices

All [[Symmetric Matrix|Symmetric Matrices]] are [[Diagonalizable]]

## Diagonalizability of Defective Matrices

A [[Square Matrix]] can only be [[Diagonalizable]] if it is not [[Defective]].
