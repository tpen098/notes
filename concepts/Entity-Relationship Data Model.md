# Entity-Relationship Data Model

## Definition

An [[Entity-Relationship Data Model]] is a [[Data Model]] and collection of objects, called [[Entity-Relationship Data Model|Entities]] and their [[Entity-Relationship Data Model|Relationships]] with one another. [^1]
