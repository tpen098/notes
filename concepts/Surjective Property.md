# Surjective Property

## Requirement

A [[Linear Mapping]] has the [[Surjective Property]] if it satisfies the following requirement [^1]

$$
\Phi(\mathcal{V}) = \mathcal{W}
$$

Meaning any [[Vector Space|Vector]] in $\mathcal{W}$ can be reached from $\mathcal{V}$ [^1]
