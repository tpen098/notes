# Static-Dynamic Variable

## Definition

A [[Static-Dynamic Variable]] is a [[Program Variable]] that is [[Binding|Bound]] when their declaration is elaborated but their types are in [[Binding|Static Bind]]. [^1]


> [!Example] Example
> An example of a [[Static-Dynamic Variable]] is setting the size of an array before using it `array[100]`
