# Binding

## Definition

A [[Binding]] is an association between an attribute and an entity, such as a [[Program Variable|Variable]] and its [[Data Type]] or value, or between an operator and a symbol [^1]

### Static Binding

A [[Binding]] is static if it occurs before run time begins and remains unchanged throughout the [[Program]] [^1]

### Dynamic Binding

A [[Binding]] is dynamic or late when it is assigned during run time [^1]

## Reference

[^1]: Concepts of Programming Languages, Ch. 5, pp. 227 - 334
