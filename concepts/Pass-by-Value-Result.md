# Pass-by-Reference

## Definition

[[Pass-by-Reference]] is an implementation model for parameter passing in [[Subprogram Parameter|Subprogram Parameters]] where an access path, commonly via a [[Memory Address]], is provided to enable direct read and write access to the [[Subprogram Parameter|Actual Parameter]] via the [[Subprogram Parameter|Formal Parameter]].
