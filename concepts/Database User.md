# Database User

## Naive User

Unsophisticated users who interact with the system using predefined user interfaces such as web or mobile applications. [^1]

## Application Programmer

Computer professionals who write application [[Program|Programs]]. [^1]

## Sophisticated User

Interacts with the system without writing [[Program|Programs]]. They make direct requests using [[Query Language|Query Languages]] or Data Analysis Tools. [^1]

## Specialized User

Writes specialized [[Database Application|Database Applications]] that do not fit the traditional data-processing framework. They store information like graphic data, audio, or video. [^1]
