# Primary Key

## Definition

A [[Primary Key]] is a [[Candidate Key]] chosen by the database designer as the principal or main means to identify [[Tuple|Tuples]] in a [[Relational Data Model|Relation]]. They are often underlined to distinguish between other attributes or keys. If there are more than one [[Primary Key]], this means all of those keys must be used collectively as a [[Candidate Key]] to properly identify. [^1]
