# Conditional Cumulative Distribution Function

## Definition

Given [[Random Variable|Random Variables]] $X, Y$, the [[Conditional Cumulative Distribution Function]]_ $p(x|y)$ is defined as the [[Probability]] of $X \le x$ given that $Y \leq y$ is guaranteed.

From the [[concepts/Product Rule|Product Rule]], the [[Conditional Cumulative Distribution Function]] can be defined using the [[Joint Cumulative Distribution Function]] and [[Marginal Cumulative Distribution Function]] as shown

$$
p(x|y) = \frac{p(x, y)}{p(y)}
$$
