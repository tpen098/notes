# Generating Set

## Definition

Consider a [[Vector Space]] $V = (\mathcal{V}, +, \cdot)$ and a [[Set]] of [[Vector Space|Vectors]] $\mathcal{A} = \{x_1, \ldots, x_k\} \subseteq \mathcal{V}$. If every [[Vector Space|Vector]] $v \in \mathcal{V}$ can be expressed as a [[Linear Combination]] of $x_1, \ldots, x_k$, then $\mathcal{A}$ is a [[Generating Set]] of $V$.
