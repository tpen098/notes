# Conditional Probability Density Function

## Definition

Given [[Random Variable|Random Variables]] $X, Y$, the [[Conditional Probability Density Function]]_ $p(x|y)$ is defined as the [[Probability]] of $a_{i} \leq X \leq b_{i}$ given that $a_{j} \leq Y \leq b_{j}$ is guaranteed.

From the [[concepts/Product Rule|Product Rule]], the [[Conditional Probability Density Function]] can be defined using the [[Joint Probability Density Function]] and [[Marginal Probability Density Function]] as shown

$$
p(x|y) = \frac{p(x, y)}{p(y)}
$$
