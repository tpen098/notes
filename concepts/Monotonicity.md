# Monotonicity

## Increasing Definition

A [[Function]] $f(n)$ is [[Monotonicity|Monotonically Increasing]] if using a larger [[Function|Input]] results in a larger or equal [[Function|Value]] [^1]

$$
f: m \leq n \implies f(m) \leq f(n)
$$

If using a larger [[Function|Input]] results in a strictly larger [[Function|Value]], then the [[Function]] is [[Monotonicity|Strictly Increasing]] [^1]

$$
f: m \lt n \implies f(m) \lt f(n)
$$

## Decreasing Definition

A [[Function]] $f(n)$ is [[Monotonicity|Monotonically Decreasing]] if using a smaller [[Function|Input]] results in a smaller or equal [[Function|Value]] [^1]

$$
f: m \geq n \implies f(m) \geq f(n)
$$

If using a larger [[Function|Input]] results in a strictly smaller [[Function|Value]], then the [[Function]] is [[Monotonicity|Strictly Decreasing]][^1]

$$
f: m \gt n \implies f(m) \gt f(n)
$$
