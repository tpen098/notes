# Matrix Row Reduced Echelon Form

## Conditions

1. The [[Matrix]] must be in [[Matrix Row Echelon Form]]
2. All non-leading entries in a column are zero in value

> [!tip]
> The [[Identity Matrix]] is a perfect example of a [[Matrix]] in [[Matrix Row Reduced Row Echelon Form|RREF]]. However, an [[Matrix Row Reduced Row Echelon Form|RREF Matrix]] can have fully zero rows or have zero diagonals if the diagonals aren't leading
