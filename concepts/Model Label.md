# Model Label

## Definition

The [[Model Label]] $y_n$ is a vector representing a property of interest that's assumed to be associated and dependent to the vector [[Model Input]] $x_n$.

## Example

An example would be that the [[Model Input]] $x_n$ represents employee credentials (years of experience, education level, etc.) and $y_n$ represents their salary.
