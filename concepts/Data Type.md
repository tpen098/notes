# Data Type

## Definition

A [[Data Type]] is a kind of data that [[Variable|Variables]] in a [[Language|Programming Language]] may take, for which operations are automatically provided. [^1] [^2] The presence of [[Data Type|Data Types]] in a [[Language|Programming Language]] leads to better [[Readability]] overall. [^3]

## Example

In the C [[Language|Programming Language]], examples of [[Data Type|Data Types]] include `character`, `integer`, `floating point`, and `double floating point`. [^1]
