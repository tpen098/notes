# Pass-by-Reference

## Definition

[[Pass-by-Value-Result]] is an implementation model for parameter passing in [[Subprogram Parameter|Subprogram Parameters]] where the [[Subprogram Parameter|Actual Parameter]]'s value is copied into the corresponding [[Subprogram Parameter|Formal Parameter]] and, at the end of the [[Subprogram]], emits the final value of the [[Subprogram Parameter|Formal Parameter]] back to the [[Subprogram Parameter|Actual Parameter]]. It is a combination of [[Pass-by-Value]] and [[Pass-by-Result]] [^1]
