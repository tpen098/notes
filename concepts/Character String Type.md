# Character String Types

## Definition

A [[Character String Type]] consist of sequences of [[Character Type|Character Types]]. Depending on the [[Language|Programming Language]], it can be a special kind of [[Character Type|Character]] [[Array|Array]] or a [[Primitive Data Type]]. Another design consideration is whether the length of the [[Character String Type|String Type]] is static or dynamic. [^1]

## Operations

Some common operations included for [[Character String Type|Character String Types]] include the following: [^1]
- Substring reference
- Assignment and comparison
- Pattern Matching
- Concatenation
- Length Determination
- Copying
