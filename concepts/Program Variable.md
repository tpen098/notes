# Program Variable

## Definition

A [[Program Variable]] is an [[Abstraction]] of one or more [[Memory|Memory Cells]]. [^1] It can be characterized by six attributes:
- [[Name]]
- [[Memory|Memory Address]]
- Value or R-values
- [[Data Type]]
- Lifetime
- Scope
