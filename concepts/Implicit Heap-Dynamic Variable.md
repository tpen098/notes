# Implicit Heap-Dynamic Variable

## Definition

An [[Implicit Heap-Dynamic Variable]] are bound on assignment without any explicit allocation.

> [!Example] Example
> An example of an [[Implicit Heap-Dynamic Variable]] is the array assignment `high = [1, 2, 3, 4]` that [[Allocation|Allocate]] memory without explicit instructions.
