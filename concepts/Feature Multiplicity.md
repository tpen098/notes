# Feature Multiplicity

## Definition

[[Feature Multiplicity]] is a characteristic of a [[Language|Programming Language]] wherein there is more than one way to accomplish a particular operation. [^1]

For example, incrementing an [[Integer]] [[Variable]] can be done in four ways in [[Java]].

```java
count = count + 1 
count += 1
count++ 
++count
```
