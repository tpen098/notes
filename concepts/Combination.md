## Definition

A [[Combination]] of a [[Set]] with length $n$ is a [[Subset]] of $S$ with length $k$ [^1]

> [!example]
> Given a [[Set]] $S = \{ a, b, c, d \}$ then $S$ has six possible [[Combination|Combinations]] with length $k=2$
> 
> $$
> ab, ac, ad, bc, bd, cd
> $$ 

> [!note] Difference between [[Permutation]] 
> The main difference between a [[Permutation]] and the [[Combination]] is that the order doesn't matter in the [[Combination]] since it is a [[Set]] but a [[Permutation]] is a [[Finite Sequence]] so the order does matter.

## Possible Variations

For a given [[Set]] $S$ of length $n$, the number of possible [[Combination|Combinations]] $s$ with length $k$ using the [[Binomial Coefficient]] as shown[^1]

$$
s = \frac{n!}{k!(n - k)!} = {n \choose k} = {n \choose n - k}
$$
