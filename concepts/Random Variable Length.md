# Random Variable Length

## Definition

The [[Norm|Length]] of a [[Random Variable]] $X$, using the [[Covariance]] as the [[Inner Product]], is simply its [[Standard Deviation]]

$$
\lVert X \rVert
= \sqrt{ Cov[x, x] }
= \sqrt{ \mathbb{V}_{X}[x] }
= \sigma[x]
$$

> [!NOTE] Intuition for Length
> The longer a [[Random Variable]] is, the greater the uncertainty. With that assessment, a [[Norm|Length]] of $0$ means the [[Random Variable]] is deterministic (not actually random).
