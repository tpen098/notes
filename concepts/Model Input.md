# Model Input

## Definition

[[Model Input|Model Inputs]] $x_n$ are [[Vector Space|Vectors]] holding information on a subject of interest. As a [[Matrix]], each row in the [[Model Input]] represents an example, data point, instance, or subject while each column represents the the particular characteristic.

> [!tip] Row-Column Correspondence
> Depending on the implementation or use-case, the row-column correspondence might be swapped to column-row.
