# Database Administrator

## Definition

The [[Database Administrator]] is a [[Database User]] that has central control over a [[Database-Management System]]. [^1]

## Functions

1. [[Schema]] definition
2. Storage structure and access-method definition
3. [[Schema]] and physical-organization definition
4. Granting of authorization for data access
5. Routine maintenance
6. Periodically backing up the database
7. Ensuring enough storage
8. Monitoring jobs and performance

[1]: Database System Concepts, pp. 24-25.
