# Derivative Product Rule

## Definition

The [[Derivative]] or [[Partial Derivative]] of the product of two differentiable [[Function|Functions]] $f(x), g(x)$ is defined as the following

$$
\frac{ \partial (f(x)g(x)) }{ \partial x }
= \frac{ \partial f(x) }{ \partial x } g(x)
+ \frac{ \partial g(x) }{ \partial x } f(x)
$$
