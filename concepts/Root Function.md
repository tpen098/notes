## Definition

The $n-th$ [[Root Function]] is a [[Function]] that takes an [[Variable]] [[Function|Argument]] $x$ and returns the $n-th$ [[Equation|Root]] of $x$ [^1] 

$$
f(x) = \sqrt[n]{ x  }
$$
