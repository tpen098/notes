# Definition

[[Writability]] is the measure of how easily a [[Language|Programming Language]] can be used to create [[Program|Programs]] for a chosen [[Problem Domain]] [^1]

This feature is considered when discussing [[Simplicity]], [[Orthogonality]], [[Data Type|Data Types]], [[Syntax]] Design, [[Abstraction]], and [[Expressivity]]. [^1]
