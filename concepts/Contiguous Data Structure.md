# Contiguous Data Structure

## Definition

A [[Contiguous Data Structure]] is a [[Data Structure]] that implements an [[Abstract Data Type]], composed of single slabs of [[Memory]] [^1][^2]

| `x1`      | `x2`      | `x3`      | `x4`      | `x5`      | ...   |
| --------- | --------- | --------- | --------- | --------- | ---- |
| Address 1 | Address 2 | Address 3 | Address 4 | Address 5  ... .. |
