# Weak Entity Set

## Definition

An [[Identifying Entity Set|Identifying Set]] is an [[Entity Set]] the dependency of a [[Weak Entity Set]] for its existence. It is said that the [[Identifying Entity Set|Identifying Set]] owns the [[Weak Entity Set]] and has a [[One-to-many Mapping Cardinality|One-to-many Mapping]] with the [[Weak Entity Set]] [^1]
