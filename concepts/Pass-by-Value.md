# Pass-by-Value

## Definition

[[Pass-by-Value]] is an implementation model for parameter passing in [[Subprogram Parameter|Subprogram Parameters]] where the value of the [[Subprogram Parameter|Actual Parameter]] is used to initialize the corresponding [[Subprogram Parameter|Formal Parameter]]. [^1]
