# Type Checking

## Definition

[[Type Checking]] is the activity of ensuring that the operands of an operator are of compatible [[Data Type|Data Types]] .[^1]

## Static Type Checking

This is [[Type Checking|Data Type Checking]] at compilation or before run time. [^1]

## Dynamic Type Checking

This is [[Type Checking|Data Type Checking]] at run time. [^1]

## Reference

[^1]: Concepts of Programming Languages, Ch. 6, pp. 311-312
