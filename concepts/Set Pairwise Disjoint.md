# Set Pairwise Disjoint

## Definition

A [[Set Collection]] $\mathfrak{S}$ is considered [[Set Pairwise Disjoint]] if all possible [[Set]] Pairs $S_{i}, S_{j}$ are [[Set Disjoint|Disjoint]] [^1]
