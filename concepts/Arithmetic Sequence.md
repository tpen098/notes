# Arithmetic Sequence

## Definition

The [[Arithmetic Sequence]] is an [[Infinite Sequence]] wherein there is a [[Arithmetic Sequence|Common Difference]] $d$ between a value $a_{i}$ and the previous value $a_{i - 1}$ [^1]

$$
f(n) = f(n-1) + d  \atop
\langle a_{1}, a_{1} + d, a_{1} + 2d, a_{1} + 3d, \dots \rangle
$$

## Specific Value

If the [[Function|Domain]] is the [[Natural Number|Set of Natural Numbers]] $\mathbb{N}$, then the $n-th$ term is adjusted to the following [^1]

$$
a_{n} = a_{1} + (n-1)d
$$
