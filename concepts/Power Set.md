# Power Set

## Definition

Given a [[Set]] $\mathcal{S}$, its [[Power Set]] $2^{\mathcal{S}}$ is the [[Set Collection]] of all possible [[Subset|Subsets]] of [[Set]] $\mathcal{S}$ [^1]
