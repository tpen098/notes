# Gram-Schmidt Process

## Statement

Given a non-[[Orthogonal Matrix|orthogonal]] and non-[[Orthonormal|orthonormal]] [[Matrix]] $B$, [[Solving Linear Systems#Gaussian Elimination|Gaussian Elimination]] can be applied to the following [[Linear System#Augmented Matrix Form|Augmented Matrix]] to create an [[Orthonormal]] [[Matrix]].

$$
[B B^{\top}|B]
$$
