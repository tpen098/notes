# Binomial Theorem

## Definition

The [[Binomial Theorem]] is an [[Equation]] that describes the expansion of [[Exponent|Powers]] of [[Binomial|Binomials]] [^1]

$$
(x + y)^{n} = \sum_{k=0}^{n} {n \choose k} x^{k} y^{n-k}
$$

### Initial Application

The following [[Expression|Expressions]] show the implementation of the [[Binomial Theorem]] on the first two, nontrivial [[Exponent|Powers]] $\{ 2, 3 \}$ of a [[Binomial]]

$$
\begin{align}
(a + b)^{2} &= a^{2} + 2ab + b^2 \\
(a - b)^{2} &= a^2 - 2ab + b^{2}  \\
(a + b)^{3} &= a^{3} + 3 a^{2} b + 3 a b^{2} + b^{3} \\
(a - b)^{3} &= a^{3} - 3 a^{2} b + 3 a b^{2} - b^{3} \\
\end{align}
$$
