# Gamma Function

## Definition

The [[Gamma Function]] $\Gamma(\cdot)$ is a [[Function]] defined by the following [[Integral]]:

$$
\begin{align}
\Gamma(t) &:=
\int_0^{\infty} x^{t-1} exp(-x) \, dx,
t > 0 \\
\Gamma(t+1) = t \Gamma(t)
\end{align}
$$
