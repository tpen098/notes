# Explicit Heap-Dynamic Variable

## Definition

An [[Explicit Heap-Dynamic Variable]] are nameless or abstract [[Memory]] that are [[Allocation|Allocated]] and [[Deallocation|Deallocated]] by explicit, run-time instructions written by the programmer. These can only be [[Allocation|Allocated]] and [[Deallocation|Deallocated]] through [[Pointer|Pointers]] or [[Reference Data Type|References]][^1]


> [!Example] Example
> An example of an [[Explicit Heap-Dynamic Variable]] are variables in C, assigned using `malloc`
