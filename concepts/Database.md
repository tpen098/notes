# Database

## Definition

A [[Database]] is a collection of data that contains large bodies of information relevant to a given enterprise or system. [^1]

## Modes of Use

### Online Transaction Processing Mode

 A [[Database]] mode of use wherein a large number of users use the [[Database]], with each user retrieving relatively small amounts of data, and performing small updates. This is the primary mode of use for most users. [^2]

### Data Analytics Mode

A [[Database]] mode for processing data to draw conclusions and infer rules or decision procedures used to drive business decisions. [^2]
