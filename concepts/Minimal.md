# Minimal

## Definition

Consider a [[Vector Space]] $V = (\mathcal{V}, +, \cdot)$ and a [[Generating Set]] $\mathcal{A} = \{x_1, \ldots, x_k\} \subseteq \mathcal{V}$. The generating set is considered [[Minimal]] if there exists no smaller set $\tilde{\mathcal{A}} \subsetneq \mathcal{A} \subseteq \mathcal{V}$
