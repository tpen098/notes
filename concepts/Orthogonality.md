# Orthogonality

[[Orthogonality]] is a [[Language|Programming Language]] characteristic, borrowing from the concept of a mathematical [[Orthogonal]], wherein a relatively small set of primitive constructs can be combined in a relatively small number of ways to build the control and data structures of the language. Each possible combination has to be both legal and meaningful. [^1]

> [!Example] Example
> Consider the primitive data types [[Integer]], and [[Character Type|Character]], and the operators $array, pointer$. If each operator can be applied to themselves and the four primitive data types then a large number of [[Data Structure|Data Structures]] can be defined.

A lack of [[Orthogonal|Orthogonality]] means having many rules or exceptions to applying data types and operators. [^1]
