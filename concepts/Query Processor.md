# Query Processor

## Definition

The [[Query Processor]] is the component of the [[Database Engine]] that interprets, compiles, and evaluates the [[Data-Definition Language]] and [[Data-Manipulation Language]]. [^1]

## Components

### Data-Definition Language Interpreter

This interprets the [[Data-Definition Language]] statements and records the definition in the [[Storage Manager#Data Dictionary|Data Dictionary]]. [^1]

### Data-Manipulation Language Interpreter

This translates [[Data-Manipulation Language]] statements in a [[Query Language]] into an evaluation plan consisting of low-level instructions that the Query Evaluation Engine can understand. [^1]

### Query Evaluation Engine

This executes low-level instructions generated by the Data-Manipulation Language Interpreter. [^1]
