# Physical Schema

## Definition

The [[Physical Schema]] describes the [[Schema]] at the [[Database-Management System#Physical Level|Physical Level]]. This is usually hidden beneath the [[Logical Schema]] and can be changed without affecting application [[Program|Programs]]. [^1]
