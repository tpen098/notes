# Strong Typing

## Definition

A [[Language|Programming Language]] is [[Strong Typing|Strongly Typed]] if [[Type Error|Type Errors]] are always detected, requiring all operands to be determined at compile time or run time. [^1]

## Reference

[^1]: Concepts of Programming Languages, Ch. 6, p. 312
