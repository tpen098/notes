# Derivative

## Definition

Given a Univariate [[Function]] $y = f(x), x, y, h \in \mathbb{R}, h > 0$, the [[Derivative]] of $f$ at $x$ is defined as the following [[Limit]]

$$
\frac{ dx }{ dy } := \\lim_{ h \to 0 } \frac{{f(x+h)-f(x)}}{h}
$$

## Multivariate Case

For a multivariate [[Function]], the [[Partial Derivative]] is used instead
