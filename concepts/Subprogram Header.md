# Subprogram Header

## Definition

A [[Subprogram Header]] is a part of the [[Subprogram Definition]] that specifies a [[Block]] as a [[Subprogram]] of some kind, provides a [[Name]] for the [[Subprogram]], and specifies the list of [[Subprogram Parameter|Subprogram Parameters]]. [^1]
