# ASCII

## Definition

[[ASCII|American Standard Code for Information Interchange]] ([[ASCII]]) is a seven-bit [[Character Type|Character]] Code system wherein each individual bit represents a unique [[Character Type|Character]]. [^1] However, eight-bits or a byte is often used for convenience.
