# Sum Rule 1

## Definition

The [[Derivative]] or [[Partial Derivative]] of the sum of differentiable [[Function|Functions]] $f_i(x)$ is defined as the following.

$$
\frac{ \partial \left(\sum f_{i}(x) \right) }{ \partial x }
= \frac{ \partial f_{1}(x) }{ \partial x }
+ \frac{ \partial f_{2}(x) }{ \partial x }
+ \frac{ \partial f_{3}(x) }{ \partial x }
+ \dots
$$
