# Block

## Definition

A [[Block]] are code sections that have its own [[Local]] [[Variable|Variables]]. These [[Variable|Variables]] are [[Allocation|Allocated]] when the section is entered and [[Deallocation|Deallocated]] when the section is exited. [^1]
