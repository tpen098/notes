# Transaction Management

## Definition

The [[Transaction Management|Transaction Manager]] is a module of the [[Database Engine]] for handling [[Transaction|Transactions]]. [^1]

## Components

### Concurrency-Control Manager

This is responsible for controlling the [[Transaction|Transactions]] among concurrent [[Transaction|Transactions]] to ensure [[Consistency|Database Consistency]]. [^1]

### Recover Manager

This is responsible for performing failure recovery and ensuring [[Durability|Database Durability]]. [^1]
