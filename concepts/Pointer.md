# Pointer

## Definition

A [[Pointer]] is a [[Data Type]] that represents a [[Memory Address]] [^1] [^1]

## Null Definition

A [[concepts/Pointer|Null Pointer]] $NIL$ is a [[Pointer]] that does not point to any location in memory
