# Pointer

## Definition

A [[Reference Data Type]] is a [[Data Type]] that represents a [[Memory Address]] [^1] [^2]

## Null Definition

A [[concepts/Pointer|Null Pointer]] $NIL$ is a [[concepts/Pointer]] that does not point to any location in memory
