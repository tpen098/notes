# Reliability

A [[Language|Programming Language]] is said to be [[Reliability|Reliable]] if it performs its specifications under all conditions. [^1]

This feature is considered when discussing [[Simplicity]], [[Orthogonality]], [[Data Type|Data Types]], [[Syntax]] Design, [[Abstraction]], [[Expressivity]], [[Type Checking]], [[Exception Handling]], and Restricted [[Aliasing]] [^1]

## Reference

[1]: Concepts of Programming Languages, Ch. 1, pp. 37-39
