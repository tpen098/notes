# Operating System

## Definition

The layer or body of software responsible for programs to run conveniently, share memory, and enable interaction with devices. Because the [[Operating System]] uses [[Central Processing Unit|CPU]] [[Virtualization]], it is also called a [[Operating System|Virtual Machine]] [^1]

## History

Initially, [[Operating System|Operating Systems]] did not do much and were basically a set of libraries of commonly used [[Function|Functions]].
