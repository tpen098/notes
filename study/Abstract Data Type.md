# Abstract Data Type

## Definition

An [[Abstract Data Type]] is a [[Set]] of Data [[Set Membership|Elements]] with a set of operations defined on the Data [[Set Membership|Elements]]. [^1]

> [!tldr]
> It is the conceptual model of a [[Data Type]] that allows the discussion of data handling without directly considering the implementation.
