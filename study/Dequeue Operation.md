# Dequeue Operation

## Definition

The [[Dequeue Operation]] $DEQUEUE(S)$ is a specific [[Delete Operation]] wherein it removes and returns the [[Set Membership|Element]] $x$ at the relative start of a [[Data Structure]] [^1]
