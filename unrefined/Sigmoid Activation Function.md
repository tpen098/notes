# Sigmoid Activation Function

## Definition

The [[Activation Function]] can be defined using the [[Sigmoid Function]]

$$
\sigma(x) = \frac{1}{1+e^{-x}}
$$

> [!note] Differentiability
> The [[Sigmoid Activation Function]] is differentiable everywhere
