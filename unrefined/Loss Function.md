# Loss Function

## Definition

The [[Loss Function]] is a [[Function]] that maps a ground truth label $y_{n}$ and prediction $y_{n}$ to a non-negative number, referred as the [[Loss Function|Loss]], representing the objective error or discrepancy.

$$
L = f(y_{n}, \hat{y}_{n})
$$
