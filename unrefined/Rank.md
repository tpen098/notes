# Rank

## Definition

The number of [[Linear Independence|linearly independent]] columns of a [[Matrix|matrix]] $A \in \mathbb{R}^{(m \times n)}$, or the number of linearly independent rows is called the [[Rank]] of $A$

$$
rk(A)
$$

## Invariance on Matrix Trace

$$rk(A) = rk(A^{\top})$$

## Matrix Inversion

[[Matrix Inverse|Matrix inversion]] can only be done ($A$ is invertible) if and only if $rk(A) = n$
