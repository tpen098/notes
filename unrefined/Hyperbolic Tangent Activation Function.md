# Hyperbolic Tangent Activation Function

## Definition

The [[Activation Function]] can be defined using the [[Hyperbolic Tangent Function]]

$$
\sigma(x) = \tanh(x)
$$

> [!note] Differentiability
> The [[Hyperbolic Tangent Activation Function]] is differentiable everywhere
