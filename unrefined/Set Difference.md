# Set Difference

## Definition

The [[Set Difference]] between two [[Set|Sets]] $A, B$ is defined as the [[Set]] wherein the [[Set Membership|Elements]] are [[Set Membership|included]] in [[Set]] $A$ but not in [[Set]] $B$ [^1]

$$
A - B = \{ x: x \in A, x \not\in B\}
$$
