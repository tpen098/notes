# Tree Terminologies

## Components

### Root

First node where all nodes originate from

### Edge

The connecting link between two nodes. Note that a tree has (n-1) edges

### Parent Node

 A node that has one or more children Node

### Child Node

A descendant of a parent node

### Internal or Non-terminal Node

Node that has at least one child

### Leaf or Terminal Node

Node that doesn't have a children

### Sibling Nodes

Nodes that belong to the same parent node

## Properties

### Degree

Node: Number of children; Tree: Highest degree of a Node in it

### Level or Depth

Each step from top to bottom (root is level 0, its children is 1, and so on)

### Height

Edges needed to traverse to go from the subtree's leaf node to the node (root node is zero height, root is max height)

## Miscellaneous

### Forest

Set of unconnected or disjoint trees
