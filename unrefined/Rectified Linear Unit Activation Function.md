# Rectified Linear Unit Activation Function

## Definition

The [[Activation Function]] can be defined using the [[Rectified Linear Unit Activation Function]]

$$
\sigma(x) = ReLU(x) = 
\begin{cases}
0, & x < 0 \\
x, & x \geq 0 \\
\end{cases}
$$

> [!note] Differentiability
> The [[Rectified Linear Unit Activation Function]] is differentiable everywhere except $x=0$.
