# Convex Set

## Definition

A [[Set]] $\mathcal{C}$ is a [[Convex]] if $\forall x, y \in \mathcal{C}$, and for any scalar $0 \leq \theta \leq 1$, the following is true

$$
\theta x + (1 - \theta)y \in C
$$
