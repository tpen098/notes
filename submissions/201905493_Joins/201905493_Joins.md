# Lab Exercise 05: Intermediate SQL Queries

This is the PDF submission required for the fifth optional lab exercise in CS 197 FZZQ, submitted by Stephen Singer on September 28, 2026.

## Beverage Products

> [!example] First Instruction
> List down all the products that are in the Beverages category. Display the Product ID, Product Name, and the Category Name. Sort using the Product ID.

```sql
-- Query 1: Beverage products
SELECT 
    product.ProductID,
    product.ProductName,
    category.CategoryName
FROM
    products product
        JOIN
    categories category ON product.CategoryID = category.CategoryID
WHERE
    category.CategoryName = 'Beverages'
ORDER BY product.ProductID;
```

## Ordered Products

> [!example] Second Instruction
> Find the subset of products that have been ordered. Display the Product ID, ProductName, Category Name, and Order ID. Sort using the Order ID.

```sql
-- Query 2: Ordered Products
SELECT 
    product.ProductID,
    product.ProductName,
    category.CategoryName,
    orderdetail.OrderID
FROM
    products product
        JOIN
    categories category ON product.CategoryID = category.CategoryID
        JOIN
    `order details` orderdetail ON product.ProductID = orderdetail.ProductID
WHERE
    category.CategoryName = 'Beverages'
ORDER BY orderdetail.OrderID;
```

## Addressed Orders

> [!example] Third Instruction
> Using the Order ID, you can identify the City Address of the Customers. Display the Product ID, ProductName, Category Name, and the Ship City. Sort using the Ship City.

```sql
-- Query 3: Addressed Orders
SELECT 
    product.ProductID,
    product.ProductName,
    category.CategoryName,
    order_inst.ShipCity
FROM
    products product
        JOIN
    categories category ON product.CategoryID = category.CategoryID
        JOIN
    `order details` orderdetail ON product.ProductID = orderdetail.ProductID
        JOIN
    orders order_inst ON orderdetail.OrderID = order_inst.OrderID
WHERE
    category.CategoryName = 'Beverages'
ORDER BY order_inst.ShipCity;
```

## Products from Portland and Seattle

> [!example] Fourth Instruction
> Update the WHERE clause to filter by only the Products bought from Portland and Seattle. Display the Product Name and Ship City. Sort by City and then sort by Product Name.

```sql
-- Query 4: Products from Portland and Seattle
SELECT 
    product.ProductName, order_inst.ShipCity
FROM
    products product
        JOIN
    categories category ON product.CategoryID = category.CategoryID
        JOIN
    `order details` orderdetail ON product.ProductID = orderdetail.ProductID
        JOIN
    orders order_inst ON orderdetail.OrderID = order_inst.OrderID
WHERE
    category.CategoryName = 'Beverages'
        AND order_inst.ShipCity IN ('Portland' , 'Seattle')
ORDER BY order_inst.ShipCity , product.ProductName;
```

## Unique Products

> [!example] Final Instruction
> Display only unique rows by using the SELECT DISTINCT instead of SELECT.

```sql
-- Query 5: Unique Products
SELECT DISTINCT
    product.ProductName, order_inst.ShipCity
FROM
    products product
        JOIN
    categories category ON product.CategoryID = category.CategoryID
        JOIN
    `order details` orderdetail ON product.ProductID = orderdetail.ProductID
        JOIN
    orders order_inst ON orderdetail.OrderID = order_inst.OrderID
WHERE
    category.CategoryName = 'Beverages'
        AND order_inst.ShipCity IN ('Portland' , 'Seattle')
ORDER BY order_inst.ShipCity , product.ProductName;
```
